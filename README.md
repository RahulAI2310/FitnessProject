# 🏋️‍♂️ Fitness Tracker Application

A full-stack web application that helps users plan, track, and monitor their workouts and fitness goals. The project allows user registration, workout logging, goal setting, and performance visualization.

---

## 🚀 Features

- ✅ User Registration and Login
- ✅ Add/View/Edit/Delete Workouts
- ✅ Track Exercise Progress (sets, reps, weight)
- ✅ Set and Monitor Fitness Goals
- ✅ Dashboard with Analytics and Charts (Progress Over Time)
- ✅ RESTful APIs (Spring Boot)
- ✅ Responsive Frontend (React.js)
- ✅ MySQL Database Integration

---

## 💻 Tech Stack

| Layer        | Technology         |
|--------------|--------------------|
| Frontend     | React.js, HTML, CSS, Bootstrap |
| Backend      | Java, Spring Boot, REST APIs |
| Database     | MySQL |
| Tools & Others | Postman, Git, GitHub, Maven/Gradle |
